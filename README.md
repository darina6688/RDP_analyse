## 📊 Автоматизация аналитики по РДП  

Автоматизированный инструмент для анализа и визуализации динамики маржи по региональным директорам по продажам (РДП).  
Скрипт обрабатывает Excel-файл с историческими данными, строит графики динамики и ранжирования, а также формирует PowerPoint-презентацию для удобного отчёта.  

**Технологии:**  Python, pandas, matplotlib, seaborn, python-pptx  
**Описание:**  
Автоматизированный анализ ежемесячной динамики маржи по каждому руководителю направления продаж (РДП). Скрипт выполняет следующие задачи:  
- Загружает данные из Excel-файла с помесячной статистикой по РДП.  
- Рассчитывает средние значения маржи за заданный период (например, 2024 год).  
- Сравнивает показатели за два последних месяца (например, май и июнь 2025) и вычисляет абсолютные и процентные отклонения.  
- Формирует ранжированные списки РДП по уровню маржи.  
- Строит графики динамики маржи по каждому РДП и столбчатые диаграммы для сравнения.  
- Автоматически генерирует презентацию в формате PowerPoint, включающую все визуализации и сводную таблицу, готовую к использованию в управленческом отчёте.
  

**Цель проекта:**  
Сократить время на подготовку регулярной аналитической отчётности для коммерческого департамента, обеспечив при этом прозрачность и воспроизводимость расчётов.  
  
**Результат:**  
Полностью автоматизированный pipeline от сырых данных до готовой презентации, который можно легко адаптировать под другие метрики и периоды. Данный процесс максимально упростил подготовку необходимых данных к еженедельным встречам с топ-менеджментом компании.   

  
**Как использовать**   
1. Подготовьте данные: Сохраните ваши данные в Excel-файл с указанными выше колонками.  
2. Обновите путь к файлу в ячейке ноутбука:  path = 'рдп_данные_29_06.xlsx'  
3. Запустите ноутбук rdp_analyse_new.ipynb.
   - Будут сгенерированы графики динамики маржи по каждому РДП
   - Построены столбчатые диаграммы ранжирования за два последних месяца
   - Создана презентация Динамика_по_РДП_YYYY-MM-DD.pptx в папке output/  
  

**💡 Совет:**  Чтобы адаптировать под другой период или другие метрики — измените параметры в функции analyse_rdp() и margin_rdp().
