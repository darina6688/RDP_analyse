## Автоматизация процесса получения аналитики по РДП

В данном проекте собирается аналитика по РДП.
Сбор осуществляется на основе файла с данными показателя Маржи по каждому РДП за определенный период в эксель.
Строятся графики, показывающие ранжирование РДП по данному показателю. Также текущие значения показателя сравниваются со среднегодовыми значениями и определяется % отклонения данного показателя по каждому РДП. 
В результате выполнения приведенного кода строятся графики динамики изменения % маржи по каждому РДП. 
Все графики автоматически сохраняются в указанной папке, а также создается шаблон презентации в Power Point. 
Данный процесс максимально упростил подготовку необходимых данных к еженедельным встречам с топ-менеджментом компании.
